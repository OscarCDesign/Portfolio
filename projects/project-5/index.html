/ Overview

The Vision

Nutricia is a nutrition clinic that provides specialized services and benefits to the student community at ITESO. Previously, the clinic relied on an external application for patient follow-ups, which restricted client interactions and service management. Furthermore, their appointment scheduling was handled entirely through email, creating a cumbersome and inefficient process for both the staff and the clients. They needed a system that could unify all the disparate functions.

/ The Challenges

Visual Direction

By utilizing the horizontal line as a core motif, the application communicates transition, process, and consistency. Everything in the design parts from this line as the primary narrative element, serving as the foundation for navigation, interaction, and information hierarchy.

/ The Challenges

Appointment System

To resolve scheduling conflicts caused by frequent cancellations, I integrated a "Waiting List" mechanic. This feature allows users to register for unavailable time slots; if a slot opens up, the system automatically reallocates the space.
